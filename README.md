# ParenBond

ParenBond is a parent–child guidance platform designed to help busy parents turn everyday situations into meaningful learning, communication, bonding, and life-skill development.

## Landing page

The repository contains the first responsive ParenBond landing-page implementation, built with semantic HTML, CSS, and vanilla JavaScript using the supplied ParenBond visual assets.

Core message: **Don't Just Tell Them. Help Them Understand.**
